## 📌 About Me

Hey there! 👋 I am a **Mobile Application Developer** specializing in native Android engineering, **Java (JDK 17)**, **MVVM Architecture**, and the **Firebase Ecosystem**. I enjoy building software that connects seamlessly with real-time cloud services and delivers clean, intuitive mobile experiences.

- 📱 **Mobile Focus**: Developing Android apps targeting API 34 using modern architecture components (`ViewModel`, `LiveData`, `ViewBinding`, `Navigation`).
- ☁️ **Cloud Infrastructure**: Integrating **Cloud Firestore** for real-time data sync, **Cloud Storage** for media uploads, and declarative **Security Rules**.
- 🛠️ **Engineering Quality**: Clean code practices, role-based access control (RBAC), and offline-first reactive data handling.
